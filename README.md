# zhb PhysX — лендинг и памятка

[Сайт](https://justbelieve9.github.io/box3d-studio-site/#/physx) · [Памятка PhysX](https://justbelieve9.github.io/box3d-studio-site/#/physx/guide)

Редакция 06.11.2026: PhysX **0.57.0**, Blender 5.2 LTS.
Автор — [@zhustbie](https://t.me/zhustbieblender).

## Страницы

- `#/physx`, `#/en/physx`: возможности, ограничения, обновление движка и замеры.
- `#/physx/guide`: полная русская памятка, 24 раздела, 23 команды и 144 именованных пользовательских параметра из исходников 0.57.0.
- `?section=<имя>` после маршрута: постоянная ссылка на раздел. Корень открывает PhysX.

Обзоры доступны на русском и английском; памятка пока только на русском.
Есть поиск по текущей странице, светлая/тёмная/системная тема, мобильное содержание и печать памятки через браузер.

## Замеры

Сравнение с Bullet сохранено как **архивный замер прежнего сайта** времён PhysX 0.38.1:
3000 кубов, 120 кадров, Apple Silicon без уточнённой модели CPU.
Для 0.57.0 это сравнение заново не запускалось.

Новое сравнение прежней и новой библиотек: Windows x86_64, Ryzen 9 5900X,
1152 тела, 150 кадров, 12 потоков, 8 подшагов, медиана трёх прогонов.
Измеряется только native stepping. Есть улучшения и регрессия BOX со штатным сном.
Библиотеки также собраны разными компиляторами; вклад отдельной оптимизации не изолирован.
JSON исходных прогонов и описание происхождения находятся в `data/`.

## Исходники и сборка

- `content/guide.html`: редактируемая памятка.
- `content/shell.html`: общий каркас.
- `build.py`: содержимое обзоров и генерация итогового HTML.
- `assets/site.css`, `assets/site.js`: оформление и интерактивность.
- `data/physx-reference.json`: снимок API. Обновляется `tools/update_reference.py` из нужного `zhb_physx/__init__.py` без импорта аддона.

```text
python build.py
python tools/check_site.py
node --check assets/site.js
python -m http.server 8765 --bind 127.0.0.1
```

Python 3.10+, без внешних зависимостей. CSS и JavaScript встраиваются в `index.html`.
Сайт не зависит от сторонних библиотек и шрифтов. Источник истины — перечисленные файлы;
итоговый HTML пересобирается. GitHub Pages публикует `main:/`.

Проверки: воспроизводимость сборки, маршруты, ссылки, уникальные ID, полнота снимка команд,
медианы замеров и контраст текстовых токенов. Поведение и мобильную вёрстку проверяют отдельно в браузере.

## Доступ к аддонам

Исходники и релизы PhysX приватны; сайт не предоставляет доступ к скачиванию.
Неподключённые возможности Box3D явно отделены от возможностей аддона.
