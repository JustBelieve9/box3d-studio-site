# Box3D Bake и Creative Studio — обзорный сайт

Одностраничный сайт (три раздела на клиентском роутинге) про два аддона для Blender:

- **Box3D Bake** `0.21.0` — твёрдые тела на движке [Box3D](https://github.com/erincatto/box3d)
  вместо Bullet: симуляция считается заранее через `ctypes` и выгружается в сцену
  ключами, кэшем или инстансами.
- **Creative Studio Tools** `0.4.0` — продакшен видеокреативов под мобильные игры:
  анимация по пути со стойкой и бегом, пресет файла, направляющие кропов, автосейв,
  уборка сцены и сборка проекта.

## Страницы

| Адрес | Что внутри |
|---|---|
| `#/` | Обзор, выбор аддона, требования и установка |
| `#/box3d` | Box3D Bake: пайплайн, возможности, режимы вывода, бенчмарки, ограничения |
| `#/studio` | Creative Studio Tools: модули, анимация по пути, интерактивная схема кропов, уборка сцены, сборка проекта |

## Локально

Отдельной сборки нет — это один самодостаточный `index.html` без внешних
зависимостей. Достаточно открыть файл в браузере или поднять любой статический
сервер:

```bash
python3 -m http.server 8000
```
