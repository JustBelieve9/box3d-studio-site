# zhb studio и zhb physx — обзорный сайт

Статический сайт про два аддона для Blender, автор — [@zhustbie](https://t.me/zhustbieblender):

- **zhb studio** `0.19.2` — продакшен видеокреативов под мобильные игры: пресет проекта,
  анимация по пути, направляющие кропов, режимы рендера, уборка сцены, Geo Nodes,
  прокси-текстуры, автосейв и сборка проекта.
- **zhb physx** `0.38.1` — твёрдые тела на движке [Box3D](https://github.com/erincatto/box3d)
  вместо Bullet: симуляция считается заранее через `ctypes` и выгружается в сцену
  ключами, кэшем или инстансами. **В разработке**, скачать пока нельзя.

## Страницы

Сайт разделён по аддонам — общей страницы-прослойки между ними нет. Между
аддонами ходят переключателем в шапке.

| Адрес | Что внутри |
|---|---|
| `#/studio` | zhb studio: настройка проекта, анимация по пути, кропы, рендер, уборка сцены, Geo Nodes, доставка, установка |
| `#/physx` | zhb physx: как работает, возможности, режимы вывода, замеры против Bullet, ограничения, платформы |
| `#/` | редирект на `#/studio` |

## Языки

Русская и английская версии живут в одном файле. Язык — часть адреса:
`#/studio` (ru) и `#/en/studio` (en). Переключатель сохраняет текущую страницу.

## Локально

Отдельной сборки нет — это один самодостаточный `index.html` без внешних
зависимостей. Достаточно открыть файл в браузере или поднять любой статический
сервер:

```bash
python3 -m http.server 8000
```

## Раздача
